Privacy Policy

Last updated: 2 October 2026

What data Reel Studio uses

When its owner connects a TikTok account, Reel Studio receives from TikTok:

  • an access token and a refresh token, used to upload and publish videos;
  • basic profile information (display name, username, avatar), shown so that the owner can see which account will post;
  • the posting options TikTok allows for that account (privacy choices, maximum video length), and the status of uploads.

Where it is kept

Everything stays on the owner's own computer: the tokens are kept in a file that only the owner can read. Reel Studio has no server and no database, and it does not collect analytics.

Sharing

Reel Studio does not sell or share any data. It sends videos and captions only to TikTok, and only when the owner publishes them.

Other users

Reel Studio does not collect any information about other TikTok users or viewers.

Deleting your data

"Disconnect account" in Reel Studio revokes the token with TikTok and deletes it from the computer. You can also remove access under Security > Manage app permissions in the TikTok app.
